# Data

This directory contains the grading standards, sample images and annotations, and generated fine-tuning datasets for Task1--Task3.

## Structure

```text
Data/
├── Expert_Standards/
│   ├── Task1.txt
│   ├── Task2.txt
│   └── Task3.txt
├── Sample_Dataset/
│   ├── Task1/
│   ├── Task2/
│   └── Task3/
├── Fine-Tuning_Dataset/
│   ├── Task1_Fine-Tuning_Dataset.json
│   ├── Task2_Fine-Tuning_Dataset.json
│   ├── Task3_Fine-Tuning_Dataset.json
│   └── Multi-Task_Fine-Tuning_Dataset.json
└── README.md
```

Each task in `Sample_Dataset` contains:

```text
<Task>/
├── Reference_dataset/
├── Train_dataset/
└── Test_dataset/
```

## Files

| Path | Function |
|---|---|
| `Expert_Standards/Task1.txt` | Tension-clamp crimping grading standard. |
| `Expert_Standards/Task2.txt` | Guying-fitting corrosion grading standard. |
| `Expert_Standards/Task3.txt` | Tangent-tower bird-nest grading standard. |
| `Sample_Dataset/` | Original JPG images and same-stem annotation JSON files. |
| `Fine-Tuning_Dataset/` | LLaMA-Factory datasets generated from the training samples. |

## Data

The image-paired JSON annotations were generated by a commercial MLLM and then checked and corrected by domain experts and annotators. They are used as follows:

| Directory | Use |
|---|---|
| `Reference_dataset` | Reference examples and expert-reviewed answers inserted into Prompt 3 and Prompt 4. |
| `Train_dataset` | Expert-reviewed supervision used to construct the fine-tuning datasets. |
| `Test_dataset` | Ground-truth grades and expert CoT used for performance and CoT evaluation. |

Sample counts:

| Task | Reference | Train | Test | Grades |
|---|---:|---:|---:|---|
| `Task1` | 4 | 6 | 6 | Else, Kind |
| `Task2` | 3 | 9 | 9 | Else, Kind, Major |
| `Task3` | 4 | 12 | 12 | Else, Kind, Major, Urgent |

`Sample_Dataset` stores the original images. Resolution-specific copies are stored in `1_Data_Processing/results/images`.
